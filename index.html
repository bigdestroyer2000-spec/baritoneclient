FAQ

What does Baritone do?

It finds and follows paths through the Minecraft world for you, including walking, mining, and building to a target.

How do I install it?

Download the file that matches your Minecraft version and place it in your mods folder. Check the official project page for loader-specific instructions.

How do I use it?

You control it with chat commands. The official documentation lists every command and setting.
