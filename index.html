FAQ

How do I install Meteor Client?

Meteor runs on Fabric. Create a Fabric profile in your Minecraft launcher for the version you want, open that profile's mods folder, and drop the Meteor .jar file into it. Launch the game, and you should see a Meteor label in the top right corner of the screen. For more detail, see Meteor's own FAQ.

How do I install Baritone?

Download the file that matches your Minecraft version and put it in your mods folder, the same way you would any other mod. Check the official Baritone project for loader-specific instructions.

How do I use Baritone?

You control it with chat commands. By default every command starts with #. The official project lists all the commands and settings.

Can I use Baritone with Meteor Client?

Yes. Meteor doesn't bundle Baritone anymore, so anything in Meteor that depends on it stays off until you put the Baritone file in your mods folder yourself.

How do I open the Meteor GUI?

Press Right Shift by default. You can change the key in Minecraft's controls menu. Inside the GUI, left-click a module to switch it on or off, and right-click it to open its settings.

How do I use the HUD?

Open the HUD tab at the top of the GUI and tick the Active box. Change any settings you like, then press Edit to move things around in the HUD editor. A red highlight on an element means it's off. Left-click toggles it and right-click opens its settings.

How do I import and export configs?

Use copy and paste inside the GUI: Ctrl + C and Ctrl + V on Windows and Linux, or ⌘ + C and ⌘ + V on Mac. It works on a single module or a whole tab such as GUI, Config or HUD.

Does Meteor work with OptiFine?

No. Meteor doesn't support OptiFine. Popular Fabric alternatives are Sodium for performance, Lithium for server optimisation, Iris Shaders for shader packs, and Moonrise for the built-in server.

How do I use the proxy system?

It works like a normal SOCKS proxy. If you're not sure what that is, look up how proxies work before you use it.
