How to install Baritone and Meteor Client

A short guide for Minecraft with Fabric. It takes about five minutes.

  1. Download the files

    Get Meteor Client and Baritone from the downloads on the home page. Pick files that match the Minecraft version you play. A mismatch is the most common reason a mod does not load.

  2. Install Fabric

    Meteor Client runs on Fabric. Download the installer from fabricmc.net, choose your Minecraft version, and run it. This adds a Fabric profile to the Minecraft launcher.

  3. Open your mods folder

    Windows: press Win + R, type %appdata%\.minecraft\mods and press Enter. macOS: ~/Library/Application Support/minecraft/mods. Linux: ~/.minecraft/mods. If there is no mods folder, create one. If you use a separate launcher profile or instance, use that instance's own mods folder instead.

  4. Add the mod files

    Copy the Meteor Client .jar and the Baritone .jar into the mods folder. Baritone is not bundled with Meteor, so anything in Meteor that needs it stays off until Baritone is in the folder.

  5. Launch the Fabric profile

    Start the Fabric profile from the launcher. When Meteor loads, a Meteor label appears in the top right corner of the screen. Press Right Shift to open its menu.

  6. Use Baritone

    Baritone is controlled with chat commands. By default they start with #. The official Baritone project lists every command and setting.

If something goes wrong

If the game crashes or the Meteor label does not appear, first check that every file matches your Minecraft version. Meteor does not support OptiFine, so remove it, and use Fabric mods such as Sodium, Lithium or Iris instead. For more answers, see the FAQ or Meteor's own FAQ.
